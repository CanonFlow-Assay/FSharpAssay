# FSharpAssay playgrounds

- [M5 Shape New and Converge](m5/README.md): four-project Domain/Application/Shell sample, 15 behavior/representation/architecture tests and an isolated packaged FsAssay consumer. Analyzer authority remains Inconclusive because separately executed test results are not ingested.
- [Decision Assist](decision-assist/README.md): execute real mutations of the M5 domain, compare six original assertions with twelve expanded assertions, retain invalid/surviving/failed-baseline cases and inspect source-bound evidence. Native F# advice never grants a verification verdict.

- [Application assessment](application-assessment/README.md): locally packaged native F# API, actual FsAssay receipt integration, named-test requirements, baseline/change lifecycle, registered offline advice and freshness/adversarial controls. The separate application review state never grants an FsAssay Pass.

All use the repository's pinned SDK 10.0.301. The experimental Web UI and Desktop are separate frozen surfaces; these command-line samples do not promote them.

See [phase-1 portable convergence](CONVERGENCE.md) for the next bounded F# shell
candidate and its evidence limits.

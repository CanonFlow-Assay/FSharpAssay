# F# Decision Assist playground instructions

Read the root README and this directory's README before changes. Keep native F# advice and evidence execution separate. Decision.fs is pure and uses discriminated unions; process, file and JSON work belongs in Run.fsx or Inspect.fsx.

This is a fixed corpus over copies of the existing M5 Order.fs and Pricing.fs. Never mutate original source during an experiment, weaken M5 policy or change expected findings to conceal a result. Preserve original assertions when extending the expanded selection and update named requirements deliberately. A compiler failure is Invalid, a failed original baseline prevents investigation, and a survivor requires review; it is not equivalent by default.

Use the exact repository SDK. Run the full corpus after executable/source-registry changes and inspect its receipt. Keep generated evidence ignored under artifacts/. Never replace an existing output directory. Missing, malformed, interrupted, modified or stale evidence must remain unavailable. The pure reducer cannot grant Pass, waive tests or execute a command. FsAssay 1.0.4 does not ingest these separate test reports. Human Gate C and zero blocking-rule admissions remain unchanged.

Do not make provider calls or publish packages/source as part of this sample.
